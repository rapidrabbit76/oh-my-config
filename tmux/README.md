# Tmux Configuration

Catppuccin Mocha themed tmux setup with enhanced status bar, pomodoro timer, and cross-platform support (macOS / Linux).

---

## Install

### One-liner (curl)

```bash
bash <(curl -fsSL https://raw.githubusercontent.com/rapidrabbit76/oh-my-config/main/tmux/install.sh)
```

### One-liner (wget)

```bash
bash <(wget -qO- https://raw.githubusercontent.com/rapidrabbit76/oh-my-config/main/tmux/install.sh)
```

### From source

```bash
git clone https://github.com/rapidrabbit76/oh-my-config.git
cd oh-my-config/tmux
./install.sh
```

### Uninstall

```bash
cd oh-my-config/tmux
./install.sh --uninstall
```

## What the installer does

1. Check for tmux / git / Nerd Font (offers a brew upgrade when tmux < 3.6)
2. Install tmux if missing (brew / apt)
3. Backup existing `~/.tmux.conf` (timestamped)
4. Install managed config to `~/.config/oh-my-config/tmux/.tmux.conf`
5. Create a bootstrap `~/.tmux.conf` that sources managed config + `~/.tmux.conf.local`
6. Preserve `~/.tmux.conf.local` and copy scripts to `~/.tmux/scripts/`
7. Install TPM (Tmux Plugin Manager)
8. Reload config if tmux is running

## Config Layout

`~/.tmux.conf`
- Bootstrap file generated by the installer. It should stay minimal.

`~/.config/oh-my-config/tmux/.tmux.conf`
- Managed config from this repo. Replaced on install/update (auto-updated once a day, see the [root README](../README.md#auto-update)).

`~/.tmux.conf.local`
- Your machine-specific or personal overrides. Never overwritten once it exists.

If the installer finds an existing custom `~/.tmux.conf`, it migrates that file to `~/.tmux.conf.local` on first install.

## Status Bar

Two lines at the top, browser style — tabs get the whole first line, widgets sit below.

```
 session │ 0 tab │ 1 tab │ 2 tab …
                     dir │  git │ 󰛳 ↓1K ↑0B (2.4G) │  CPU │  RAM │ 󰋊 disk │ 🔋 bat │ 󰩟 IP │ 🍅 pomo │  date
```

- The current tab has a peach number and a lighter background; long names are cut with `…`.
- Unnamed tabs follow the shell's folder, or the running program (`nvim`, `yazi`, …). A name set with `Prefix + ,` sticks.
- `Prefix + b` switches to a **side tab list**: a 28-column panel on the left of every window
  (jump with a number key or a click) and a single status line. Press it again to return.

| Segment | Color (Mocha) | Script |
| --- | --- | --- |
| Git branch | Green `#a6e3a1` | inline |
| Network speed + bandwidth | Teal `#94e2d5` | `net_speed.sh` |
| CPU | Blue `#89b4fa` | tmux-cpu plugin |
| RAM | Yellow `#f9e2af` | tmux-cpu plugin |
| Disk usage | Peach `#fab387` | `disk_usage.sh` |
| Battery | Pink `#f5c2e7` | tmux-battery plugin |
| Public IP | Lavender `#b4befe` | `public_ip.sh` (5min cache) |
| Pomodoro | Red `#f38ba8` | `pomodoro.sh` |

## Keybindings

### Prefix

| Key | Action |
| --- | --- |
| `Ctrl+Space` | Primary prefix |
| `Ctrl+b` | Secondary prefix |

### Pane Navigation (no prefix)

| Key | Action |
| --- | --- |
| `Option+h` | Move left |
| `Option+j` | Move down |
| `Option+k` | Move up |
| `Option+l` | Move right |

### Pane Navigation (prefix)

These are shipped in the default `~/.tmux.conf.local` template so they survive reinstalls.

| Key | Action |
| --- | --- |
| `Prefix + h` | Move left |
| `Prefix + j` | Move down |
| `Prefix + k` | Move up |
| `Prefix + l` | Move right |

### Window & Pane

| Key | Action |
| --- | --- |
| `Prefix + %` | Split horizontal |
| `Prefix + "` | Split vertical |
| `Prefix + L` | Last window |
| `Prefix + Tab` | Yazi file explorer (50% split) |
| `Prefix + f` | Search tabs in every session with fzf (falls back to `choose-tree`) |
| `Prefix + b` | Toggle side tab list |
| `Prefix + r` | Reload config |

### Pomodoro Timer

| Key | Action |
| --- | --- |
| `Prefix + P` | Start/stop toggle (25min work) |
| `Prefix + O` | Stop timer |

Work → Break transition is automatic (25min work → 5min break).

### Copy Mode (vi)

| Key | Action |
| --- | --- |
| `v` | Begin selection |
| `y` | Copy to clipboard |
| `Enter` | Copy to clipboard |
| Mouse drag | Copy (no clear) |
| Scroll wheel | 5 lines per tick |

## Requirements

- **tmux** >= 3.6 (older versions break decomposed Korean filenames, e.g. in yazi)
- **git** (for TPM)
- **Nerd Font** (for icons) — e.g., Hack Nerd Font, D2Coding Nerd Font
- Terminal with true color support
